# Machine learning predicts microbial diversity
We developed a machine-learning workflow to predict bacterial and microeukaryotic community β-diversity across water, sediment, and soil habitats. The workflow integrated climatic and physicochemical variables with community assembly metrics, including the β-diversity of taxa linked to dispersal limitation and the relative importance of dispersal limitation, and benchmarked nine regression algorithms after collinearity filtering. The best-performing models were then used to assess predictor importance and screen environmental and assembly conditions associated with higher predicted β-diversity.

#Analysis workflows
1) Bacteria

The `bacteria/` directory contains the workflow for predicting bacterial community β-diversity.

- `input data/` contains the input datasets for water, sediment, and soil.
- `ml_16s_all.R` is the R script for running the bacterial β-diversity prediction workflow.
- `results_bacteria/` contains the output files generated by the analysis.

2) Microeukaryotes   
The `microeukaryotes/` directory contains the workflow for predicting microeukaryotic community β-diversity.

- `input data/` contains the input datasets for the analysis.
- `ml_18s_all.R` runs the microeukaryotic β-diversity prediction workflow.
- `results_microeukaryotes/` contains the output files generated by the analysis.
  
3) Running the analyses
Run the R script in the directory for the group of interest:

- For bacteria, run `bacteria/ml_16s_all.R`.
- For microeukaryotes, run `microeukaryotes/ml_18s_all.R`.

Each script uses the corresponding input data and saves its output files in the relevant results directory.
